Architecture Overview

This project implements a cost optimized AWS cloud architecture designed to demonstrate scalability concepts while staying within Free Tier limits.

VPC
A custom VPC is created with a single IPv4 CIDR block. One public subnet is configured inside the VPC. An Internet Gateway is attached to allow inbound and outbound internet access.

Subnet
The public subnet hosts all resources. Auto assign public IP is enabled to allow EC2 internet access without additional networking services.

EC2
A single EC2 instance using t2.micro or t3.micro is launched inside the public subnet. The instance runs a basic Apache web server. The default EBS root volume is used for storage.

Application Load Balancer
An Application Load Balancer is placed in front of the EC2 instance. It routes HTTP traffic to the target group. Health checks are enabled to monitor instance availability. The load balancer is used only for learning and short testing to avoid cost.

Auto Scaling
An Auto Scaling Group is created using a Launch Template. Minimum capacity is set to one. Maximum capacity is set to one. Desired capacity is set to one. Scaling policies exist but no additional instances are launched.

AMI
A custom AMI is created from the configured EC2 instance. This AMI is used in the Launch Template to ensure consistent deployments and fast recovery.

Security
Security Groups allow inbound HTTP traffic on port 80. SSH access on port 22 is restricted to a specific IP address. Outbound traffic is allowed.

Design Goals
Learn AWS architecture fundamentals.
Understand cost control techniques.
Demonstrate scalability concepts without increasing resource usage.
